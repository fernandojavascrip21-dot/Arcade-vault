# Informes de seguridad

El agente `security-auditor` guarda aquí un informe Markdown nuevo por cada auditoría bajo
demanda. Los nombres siguen `YYYY-MM-DD-auditoria-seguridad.md`; si hay más de una auditoría
en la misma fecha, se añade `-02`, `-03`, etc. Los informes anteriores se conservan.

`references/security-checklist.md` es la línea base de controles y excepciones; los
informes de esta carpeta registran lo observado en cada ejecución.
